# 🔐 JavaScript Cryptography Lab

This repository contains JavaScript programs completed as part of my Cryptography Lab coursework. Each program demonstrates fundamental JavaScript concepts while solving cryptography and programming-related problems.

## 📚 Programs Included

| No. | Program |
|----|---------|
| 1 | Print "Hello, Cryptography!" on the console |
| 2 | Read two integers and display their sum |
| 3 | Check whether a number is even or odd |
| 4 | Find the largest of three numbers |
| 5 | Reverse a given string |
| 6 | Check whether a string is a palindrome |
| 7 | Count the number of vowels in a string |
| 8 | Generate the multiplication table of a given number |
| 9 | Count the number of digits in an integer |
| 10 | Implement a Caesar Cipher with a shift value of 3 |

## 🛠️ Technologies Used

- JavaScript (Node.js)
- Visual Studio Code
- Git & GitHub

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/madhusudhan1260/JavaScript-Cryptography-Lab.git
```

2. Navigate to the project folder

```bash
cd JavaScript-Cryptography-Lab
```

3. Run any program

```bash
node proj1.js
```

Replace `proj1.js` with the required program file (e.g., `proj5.js`, `proj10.js`).
